# Offense
How the scores work

Raw BST counts every base stat, including an attacking stat the Pokémon never uses. Effective BST counts only the stats it actually uses.

Simple Sum

HP + Def + SpD + attacking stat + Spe. In Trick Room, Speed is subtracted instead: HP + Def + SpD + attacking stat − Spe, so slower Pokémon score higher.

Focus and Speed

Bulk scores only HP + Def + SpD, which suits support Pokémon that don't need to attack. Offense scores only the attacking stat. Speed adds Speed to whichever view you pick, or subtracts it in Trick Room. Bulk with Speed on is a support score. Turn Speed off for pure tankiness or pure power; Trick Room has no effect while Speed is off.

BSR

Based on Smogon's Base Stat Rating. Bulk is HP × Def and HP × SpD. Offense scales the attacking stat by the share of the pool this Pokémon outspeeds, or in Trick Room the share it moves before. Each part is standardized across the pool, then the total is rescaled so the average matches Simple Sum (450).

Offense

Each Pokémon uses its higher attacking stat. When the lower one is at least 75% of the higher, you can switch it to Phys, Spec or Both. Crossed-out stats aren't counted. Your picks are saved in this browser.

Base stats come from Pokémon Showdown's data for VGC 2026 Reg M-C. Mythical and Restricted Legendary Pokémon are excluded, and Megas are listed separately.
